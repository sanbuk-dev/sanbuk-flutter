## 0.1.0

* First release. Android only.
* `Sanbuk.init`, `Sanbuk.loadAd` for drawing an ad with your own widgets.
* `SanbukAdView` for the default renderer, drawn by the native SDK.
* `SanbukFullscreen.load` / `.loadRewarded` / `.show` for interstitial and
  rewarded ads, with the interruption rules enforced natively.
* Wraps `ir.sanbuk:sdk-android:0.1.0`, which travels inside the plugin — see
  the README for the one line an app has to add until that artifact is
  published to a public repository.
